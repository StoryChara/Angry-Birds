## 🚀 Instalación y Ejecución

1. Clona el repositorio:
```bash
git clone https://github.com/StoryChara/Angry-Birds.git
```

2. Abre el archivo `index.html` en tu navegador web preferido.

O simplemente accede al juego online a través de: [https://storychara.github.io/Angry-Birds/](https://storychara.github.io/Angry-Birds/)
